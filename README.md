# AdFlow Nexus

Corporate website for AdFlow Nexus — a 360° digital marketing agency focused on Performance Marketing, Content Marketing and Media Buying.

## Deployment

This is a static site designed for Cloudflare Pages.

Cloudflare Pages settings:

- Production branch: `main`
- Framework preset: `None`
- Build command: leave blank
- Build output directory: `/`

The production domain can be attached after the preview deployment is reviewed and approved.

## Structure

- `index.html` — homepage content and structure
- `styles.css` — responsive design system and animations
- `script.js` — scroll reveals and mobile navigation
